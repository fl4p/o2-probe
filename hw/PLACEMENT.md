# Rev-A final PCB placement

`o2-probe.kicad_pcb` is the only fabrication placement. The earlier unrouted
placement study and its previews were removed; fabricate only from the release
ZIP generated by `make_fab.py`.

## Controlled datums

| Item | Final value |
| --- | --- |
| Board | 20.0 × 119.0 mm, R2.0 corners, 1.0 mm, 4 layers |
| Board-local origin | cable-end left corner `(0,0)` |
| Pot line | `y=82.0 mm` |
| Gas zone | begins after transition at `y=86.0 mm` |
| Cell centre | `(10.0,93.5) mm` |
| Cell pin row | `y=91.0 mm`, toward cable/AFE |
| LMP91000 centre | `(10.0,79.5) mm` |
| LMP CELL_RE pad to cell RE pin | 9.652 mm |
| Rear-flow first-article aperture | 3.0 × 6.0 mm vertical NPTH slot, centred 2.5 mm gasward |
| U13 thermal barrier | two 7.5 × 0.8 mm transverse slots at `y=114.0 mm` |
| U13 / TP7 | U13 `(10,116)` front; TP7 `(15,116)` back |
| DNP pressure option | C23 `(15,107.5)`, U14 `(16,110)`, C24 `(18,110)`, front |
| Rounded gas end | `y=119.0 mm` |

The 6 mm gas-end reduction shortens the nominal cell-centre-to-board-end
distance from 31.5 mm to 25.5 mm. The actual cell-to-PTFE-membrane distance is
set by the enclosure stack and must be measured on the 1:1 tube coupon.

## Functional placement

- Cable end through pot line: cable lands, input protection and power, MCU,
  RS-485, programming, expansion, guarded AFE, and ADC.
- Unpotted chamber: SGX O₂ cell, SHT45, heater resistors, heater switch and
  cell-block TMP117.
- Gas-reference tip: U13 TMP117, its fitted C21/C22/R30 support parts, and TP7.
  All `/TMP_GAS_EP` copper remains gasward of the transverse barrier.
- Optional BMP390 pressure sensing is heaterward of the U13 barrier with only
  its DNP capacitors C23/C24. This option no longer consumes cold-tip length or
  adds copper across the barrier.
